# Ծախսերի հաշվիչ

## Որտե՞ղ եք պահում ծախսերի ցուցակը և ինչու այնտեղ
Ծախսերի ցուցակը պահում եմ `_HomeScreenState`-ի ներսում (`List<Expense> _expenses`), որովհետև հիմնական էկրանն է կառավարում ավելացումը, ֆիլտրումը, ջնջումը և վերականգնումը, իսկ `setState`-ով ցուցակը փոխելիս էկրանը թարմացվում է։

## Ինչպե՞ս եք հաշվում ընդհանուր գումարը, և ինչու այն չեք պահում առանձին փոփոխականում
Ընդհանուր գումարը հաշվում եմ `_totalAmount` getter-ով՝ գումարելով ներկայում երևացող (`_visibleExpenses`) ծախսերի `amount`-ները։ Առանձին փոփոխականում չեմ պահում, որպեսզի ավելացման, ջնջման կամ ֆիլտրի փոփոխության ժամանակ գումարը միշտ ճշգրիտ հաշվվի և հնացած արժեք չմնա։

## Ինչո՞ւ է Dismissible-ի key-ը expense.id, ոչ թե index
`index`-ը փոխվում է, երբ տարր է ջնջվում կամ ցուցակը ֆիլտրվում է, ինչը կարող է խառնել Flutter-ի widget-ների համապատասխանությունը։ `expense.id`-ն յուրաքանչյուր ծախսի համար եզակի է, ուստի `Dismissible`-ը միշտ ճիշտ տարրն է ջնջում ու վերադարձնում։
